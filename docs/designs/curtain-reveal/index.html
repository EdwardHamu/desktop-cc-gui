铁稳 · Mac + Win 100%

矩形面板 + translate3d / scale。不碰 clip-path、mask、3D、View Transitions。

  • 左右对开 / 上下对开
  • 整幅左 / 右 / 上 / 下
  • 四角分裂 / 中心收线
  • 竖叶 / 横叶

现代稳 · 别当 100%

仓库 min macOS 写的是 10.13。clip-path 动画要 10.15.4+。Win 没问题。

  • clip-path inset / circle
  • 静态 polygon + transform

有坑 · 不要落地

同一套 CSS 在两边看起来就不一样，或者会闪。

  • mask-image 溶解（前缀 + 边缘软硬不一致）
  • rotateY / preserve-3d（WebKit 闪面）
  • View Transitions（Safari 18+）

落地建议：会话切换用 左右对开 或 整幅上提。 对开不暗示导航方向；上提更像剧院幕布。百叶和四角好看，但会话恢复场景偏闹。 引擎：transform: translate3d() + overflow: hidden + 接缝处 50.4% 重叠，避开 1px 缝。 时长 720ms，cubic-bezier(0.16, 1, 0.3, 1)。不要上 blur / mix-blend，Windows 大面容易卡。
