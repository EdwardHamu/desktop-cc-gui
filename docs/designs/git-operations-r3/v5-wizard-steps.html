获取远端更新 1 步直出

无参数操作不需要向导：步骤轨收缩为单步「确认」。

⇓获取远端更新✕
1确认 Confirm无参数
step 1 / 1
git fetch --all仅更新远端引用元数据
◎Intent · 更新远端引用信息用于比对。
✓Will happen · 将以默认作用域 all remotes 执行 fetch。
✗Will NOT · 不会把变更合并到当前分支。
$git fetch --all
