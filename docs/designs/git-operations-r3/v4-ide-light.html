拉取变更 radio group

合并方式是天然 radio 互斥，--no-commit / --no-verify 是 checkbox。

↓拉取变更✕
git pull origin main⧉ 复制
修改选项 · 合并方式（互斥）
Intent
先从 origin 拉取 main，再把本地新增提交接到远端最新提交后面。
Will happen
本地提交重新接到远端之后，记录更整齐；冲突时暂停等你处理。
Will NOT
不会创建合并提交，也不会推送；rebase 后本地 hash 可能变化。
Example
git pull --rebase origin main

获取远端更新 minimal

一个 fieldset 装完。

⇓获取远端更新 仅更新远端引用元数据✕
git fetch --all⧉ 复制
Intent
更新远端引用信息用于比对。
Will happen
将以默认作用域 all remotes 执行 fetch。
Will NOT
不会把变更合并到当前分支。
Example
git fetch --all
