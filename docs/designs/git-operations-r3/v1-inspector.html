拉取变更 options → live explanation

选项 token 与解释表联动：点 --rebase，Will / Won't 行即时改写。

↓拉取变更✕
git pull origin main⧉ 复制
☁ origin ▾
⑂ main ▾
修改选项 合并方式互斥 · no-commit / no-verify 可叠加
--rebase--ff-only--no-ff--squash --no-commit--no-verify
Intent
先从 origin 拉取 main，再把你本地新增的提交接到远端最新提交后面。
Will Happen
本地新增提交会重新接到远端最新提交后面，记录更整齐；遇到冲突会暂停，等你处理。
Will NOT
不会创建合并提交，也不会推送到远端；rebase 之后本地提交的 hash 可能变化。
Example
git pull --rebase origin main

Will Happen
将以默认作用域 all remotes 执行 fetch。
Will NOT
