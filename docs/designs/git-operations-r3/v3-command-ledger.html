02拉取变更

选项直接长在命令行上：点 hero 里的 flag 即开关，下方 ledger 同步解释。

git pull拉取变更✕
git pull --rebase --ff-only --no-ff --squash --no-commit --no-verify origin main
合并方式互斥；当前等价命令 git pull --rebase origin main
Remote · 远端与分支
☁ origin ▾ ⑂ main ▾
Intent意图
先从 origin 拉取 main，再把本地新增提交接到远端最新提交后面。
Will happen会发生
✓ 本地提交重新接到远端之后，记录更整齐；冲突时暂停等你处理。
Will not不会发生
✗ 不创建合并提交、不推送；rebase 后本地 hash 可能变化。
Example等价命令
git pull --rebase origin main

04获取远端更新

最简形态：一行命令 + 三行 ledger。

git fetch获取远端更新✕
git fetch --all
仅更新远端引用元数据 · 作用域 all remotes
Intent意图
更新远端引用信息用于比对。
Will happen
✓ 将以默认作用域 all remotes 执行 fetch。
Will not
✗ 不会把变更合并到当前分支。
