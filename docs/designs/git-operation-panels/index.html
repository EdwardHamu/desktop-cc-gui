A · 审查台骨架

Split Composer

命令行当标题栏。左栏只放参数，右栏只放后果与提交列表。信息密度最高，push 最舒服。

B · 命令是产品

Command Ledger

对话框就是一行正在写的 git。Intent / Happen / Not 摊成三栏账本，跟着 token 变。更像终端，更少表单。

怎么选

  • 选 A：你要保留推送面板已经在用的左右审查，只换皮、把命令抬到顶上。
  • 选 B：你愿意让命令成为主角，说明书改成账本，表单尽量消失。
