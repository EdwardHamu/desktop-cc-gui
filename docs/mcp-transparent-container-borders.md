# 容器深色边框透明化

## PLAN

按用户要求去掉容器的黑/深灰色边框。当前源码未发现直接 border-black 或 #000 边框，主要由主题中性边框 token 提供。将普通边框、容器专用边框、分隔线及磨砂边缘 token 的浅/深主题与 Tailwind 映射设为 transparent，保留布局宽度。

## 范围

- 修改 src/styles/theme.css：12 个 token、36 处声明。
- 覆盖 composer、侧栏、聊天主面板、终端外框、弹出菜单、卡片、表格及设置区域使用的普通边框/分隔线。
- 共用 border-button-* token 的普通按钮和输入框边框也会透明；使用相同 token 的 ring 及滚动条 active 背景同样受影响。
- 保留彩色错误边框、键盘焦点环、复选框专用边框、文字、背景和阴影；阴影仍可能形成暗边，不将 shadow 当作 border 删除。
- 不删除 border 宽度，不新增全局 * { border: none }，不修改原生窗口边缘。
